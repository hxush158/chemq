结果集约定（结果要能直接给人看，也要能被程序比对）：
1. 月份列用 to_char(<日期列>, 'YYYY-MM') 输出，不要返回 date；问题没要求按月就不要加月份列。
2. 问「哪个/谁…最高/最低」只返回那 1 行（排序后 LIMIT 1）；问「前 N 个」返回 N 行。排序方向按问题里的方向词。
3. 环比/同比/两期对比：返回两期的原值各一行，不要压成一行差值。
4. 只返回问题要的列；比例、均值按「先 sum 再相除」在 SQL 里算好。
